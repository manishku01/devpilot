# DevPilot

DevPilot is a self-service deployment platform built using React, FastAPI, Jenkins, Docker, and PostgreSQL.

## Goals

- Register projects
- Trigger Jenkins deployments
- Monitor build status
- View deployment logs
- Deployment history
- Rollback deployments
- AI-powered deployment assistant (future)

## Tech Stack

- React
- FastAPI
- PostgreSQL
- SQLAlchemy
- Jenkins
- Docker
- GitHub
